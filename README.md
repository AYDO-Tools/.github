# AYDO Tools public profile

[profile/README.md](profile/README.md) introduces the organization on its public
GitHub Overview. The profile describes our purpose, setup flow, scope, and
working principles.

## Contents

- `profile/README.md`: public introduction in Indonesian and a Mermaid setup flow.
- `profile/assets/dashboard-header.svg`: banner in the shared AYDO style, with a
  steel-blue palette for AYDO Tools.

## Maintenance

Keep this repository public and its profile on the default branch. Keep the
introduction general: describe the tooling without publishing project names,
hostnames, subnets, or credentials. Review both text and assets before
publication.

Update the scope table when the template gains or drops a supported service.
Preserve the established banner style, and check relative image links, section
links, and Mermaid rendering after changes.
